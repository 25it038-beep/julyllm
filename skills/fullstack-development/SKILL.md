# Fullstack Development Skill

Builds and maintains fullstack applications across React, Next.js, FastAPI, Node, and Python.

## Procedure
1. **Architect**: Inspect existing repository using `file_search`.
2. **Scaffold**: Create necessary configuration files, dependencies, and entrypoints using `file_write`.
3. **Dependencies**: Install required packages inside the sandbox using `terminal_exec`.
4. **Implementation**: Generate component logic and modular routers.
5. **Verification**: Run unit test suite using `terminal_exec` to verify clean build and 0 errors.
