# Technical Research & Synthesis Skill

Gathers, validates, and summarizes facts across external web and local documentation.

## Procedure
1. Query search engine via `web_search` for topic and primary citations.
2. Navigate to authoritative reference pages using `browser_navigate`.
3. Extract clean text and summarize key takeaways.
4. Synthesize findings into structured markdown report with full citations.
