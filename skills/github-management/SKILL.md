# GitHub & Version Control Management Skill

Manages local Git workflow and remote GitHub synchronization safely.

## Procedure
1. Check repository status with `git status`.
2. Inspect uncommitted diffs with `git diff`.
3. Stage intended modifications with `git add <files>`.
4. Commit with descriptive semantic commit message.
5. Push to remote origin when authorized.
